Single Page PDF Exporter

Support page for the Chrome extension published by SQHOME-SUN.

What This Extension Does

Single Page PDF Exporter helps you export the current page, or a selected page region, as a single-page PDF while preserving layout and styles as much as possible.

Common Questions

  • If local file pages do not work, enable file URL access in Chrome extension settings.
  • If a dynamic page looks incomplete, wait until the content fully loads before exporting.
  • If selection looks too large, scroll back up during selection mode to reduce the bottom boundary.

Permissions

The extension uses browser permissions only for on-device page selection and PDF export. It does not rely on remote servers for PDF generation.
