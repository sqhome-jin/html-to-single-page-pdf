# Chrome 应用商店隐私表单（可直接粘贴）

适用扩展：Single Page PDF Exporter  
开发者：SQHOME-SUN

## 单一用途

本扩展程序的单一用途是：在用户主动触发时，将当前标签页（或用户在页面中选择的区域）导出为单页 PDF，并尽量保留原网页布局与样式。扩展仅执行页面范围选择、打印参数处理和本地保存，不提供与该用途无关的功能。

## 需请求权限的理由

### activeTab
仅在用户点击扩展并执行导出时，临时访问当前活动标签页，用于读取页面尺寸/边界并执行导出流程。不访问其他标签页。

### scripting
用于在当前页面注入并运行导出所需脚本（例如区域选择覆盖层、边界计算、导出前临时样式处理与恢复）。仅在当前活动页面生效。

### debugger
用于调用 Chrome DevTools Protocol 的 Page.printToPDF 生成高保真 PDF，并按用户选择区域输出单页结果。该权限仅用于本地导出能力实现。

### downloads
用于将已生成的 PDF 文件保存到用户设备，并支持浏览器保存流程（包括“另存为”对话框）。

### storage
用于在浏览器本地保存少量扩展设置与临时状态（例如选区边界、是否弹出保存对话框）。不用于跨站跟踪，不上传到开发者服务器。

## 您正在使用远程代码吗？

理由：扩展程序运行所需的 JS/CSS/资源文件均已打包在扩展安装包内，不通过外部 <script>、远程模块、动态 eval 远程字符串或远程 Wasm 执行代码。

## 数据使用

目前或未来计划收集的用户数据：不收集

说明：扩展不收集、存储、传输或出售个人信息。页面处理与 PDF 生成在用户本地浏览器中完成，生成文件由用户自行保存到本地设备。

若表单必须填写说明文字，可粘贴：
