# Privacy Policy Template

## Privacy Policy for Single Page PDF Exporter

Last updated: 2026-07-22

Single Page PDF Exporter, published by SQHOME-SUN, is designed to help users export the current web page or a selected page region as a single-page PDF.

## Information Collection

This extension does not collect, store, transmit, or sell personal information.

## How the Extension Works

The extension uses Chrome extension APIs locally in the browser to:
- read the currently active tab content for export processing
- allow the user to select a page region
- generate a PDF from the selected page content
- save the generated PDF using the browser download flow

## Data Handling

- Page processing happens locally on the user's device.
- Exported PDF files are saved directly by the user through the browser save dialog.
- No page content is uploaded to external servers by this extension.
- No analytics, tracking scripts, or advertising SDKs are included.

## Permissions Explanation

The extension may request the following permissions:
- `activeTab`: access the currently active tab when the user triggers export
- `scripting`: run page-side logic required for region selection and export preparation
- `debugger`: generate high-fidelity PDF output from the current page
- `downloads`: save generated PDF files
- `storage`: temporarily store selection data within the browser session

## Third-Party Services

This extension does not use remote third-party services for PDF generation or analytics.

This privacy policy may be updated from time to time. Any changes should be published together with extension updates.
