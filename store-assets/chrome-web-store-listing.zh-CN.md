# Chrome 应用商店上架文案（中文）

## 插件名称
Single Page PDF Exporter

## 开发者名称
SQHOME-SUN

## 简短描述
将当前网页或选定区域导出为单页 PDF，并尽量保留原始布局与样式。

## 宣传摘要
把简历、长网页、报表、仪表盘快速导出为清晰的单页 PDF，避免分页错乱。

## 详细描述
Single Page PDF Exporter 可以帮助你将当前网页，或者网页中的指定区域，导出为单页 PDF。

很多网页在浏览器默认打印时会出现分页不合理、布局错位、内容被截断、空白过多等问题。这个插件提供了更直接的方式：你可以精确选择导出的页面区域，然后一键保存为单页 PDF。

### 核心功能
- 将当前标签页导出为单页 PDF
- 尽量保留网页原始布局与视觉样式
- 支持通过 left / right / top / bottom 精确控制导出区域
- 支持页面内可视化区域选择
- 向下滚动时扩展导出范围
- 向上滚动时收缩底部范围，方便修正选区
- 区域选择完成后可直接触发导出
- 支持系统保存对话框，自定义文件名与保存位置

### 适用场景
- 导出在线简历为单页 PDF
- 导出长网页、报告、仪表盘、账单、内部系统页面
- 仅导出网页中的某个关键区域，而不是整页内容
- 生成便于分享、归档、提交的 PDF 文件

### 隐私说明
本插件不会依赖远程服务器生成 PDF。页面处理和 PDF 导出均在本地浏览器环境中完成。

### 说明
- 如需导出 file:// 本地页面，请在扩展设置中开启对文件 URL 的访问权限
- 对于动态加载页面，建议等待内容加载完成后再导出
