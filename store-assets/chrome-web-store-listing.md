# Chrome Web Store Listing

## Extension Name
Single Page PDF Exporter

## Developer Name
SQHOME-SUN

## Short Description
Export the current tab or selected page region as a single-page PDF while preserving layout and styles.

## Promotional Summary
Turn long web pages, resumes, dashboards, and reports into clean single-page PDFs with precise region selection.

## Detailed Description
Single Page PDF Exporter helps you capture exactly the part of a web page you want and save it as a single-page PDF.

The extension is designed for pages where the default browser print flow often breaks layouts, splits content across multiple pages, or includes too much extra area. Instead of relying on a standard print dialog alone, this extension lets you visually choose the area you want, then exports it directly as a one-page PDF.

### Key Features
- Export the current tab as a single-page PDF.
- Preserve page layout and visual styling as much as possible.
- Select an exact region using left, right, top, and bottom bounds.
- Start a visual selection flow directly on the page.
- Scroll down to expand the selected area.
- Scroll back up to reduce the bottom boundary if you selected too much.
- Export immediately after selection and choose file name and save location.
- Works well for resumes, profile pages, reports, invoices, and long-form web content.

### Typical Use Cases
- Save an online resume as a clean single-page PDF.
- Export a dashboard, internal tool, or report without pagination issues.
- Capture a specific section of a long page instead of the entire document.
- Produce polished PDF snapshots for sharing or archiving.

### Privacy
This extension does not require remote servers to generate your PDF. Page capture and PDF generation run locally in the browser using Chrome extension APIs.

### Notes
- Local file pages may require enabling access to file URLs in Chrome extension settings.
- Some highly dynamic pages may need to finish loading before export.
