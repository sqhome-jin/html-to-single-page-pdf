# Chrome Web Store Listing (English)

## Extension Name
Single Page PDF Exporter

## Developer Name
SQHOME-SUN

## Short Description
Export the current page or selected region as a single-page PDF while preserving layout and styles.

## Promotional Summary
Turn resumes, long pages, dashboards, and reports into clean single-page PDFs without broken pagination.

## Detailed Description
Single Page PDF Exporter helps you export the current web page, or an exact selected region, into a single-page PDF.

Default print dialogs often split content across multiple pages, break layouts, or include too much empty space. This extension gives you more control: visually choose the area you want and export it directly as one clean PDF page.

### Core Features
- Export the current tab as a single-page PDF
- Preserve page layout and visual styles as much as possible
- Use left / right / top / bottom bounds for precise export control
- Start a visual on-page selection flow
- Scroll down to expand the selected region
- Scroll back up to reduce the bottom boundary when needed
- Export immediately after region selection
- Choose file name and save location through the system save dialog

### Common Use Cases
- Export an online resume as a clean single-page PDF
- Save dashboards, internal tools, invoices, and reports without pagination issues
- Capture only the important section of a long page instead of the entire document
- Create polished PDF snapshots for sharing or archiving

### Privacy
This extension does not rely on remote servers to generate PDFs. Processing and export happen locally in the browser.

### Notes
- For local file pages, enable file URL access in extension settings
- For dynamic pages, wait until content finishes loading before exporting
